## 1. Що змінилось — три речі, не одна

`D` і `C` рахуються **дослівно так само**, як у baseline (ті самі пороги, та сама формула, той самий
колірний ляп із §6 baseline-документа). Змінилось те, що з ними роблять далі:

| | baseline | наше |
|---|---|---|
| ваги фьюзії | фіксовані 50/50 | обернені до дисперсії |
| що йде в канал 0 | `p` | `μ` |
| що гейтить attention | `p` — **той самий об'єкт** | `mask` — **інше число** |
| вхідні канали | `[p, R, G, B]` (`FEAT: 3`) | `[μ, R, G, B, σ²]` (`FEAT: 4`) |

Друге і третє легко проґавити. У baseline `mask = input` — буквально один тензор, тобто пріор
використовується двічі **одним і тим самим числом**. У нас вони розійшлись:

```python
data0.x[:, 0] = mu0.squeeze(-1)                  # рядок 154 — у канал 0 йде μ
data0.x = torch.cat([data0.x, var0], dim=1)      # рядок 156 — σ² додається каналом
data0.mask = mask0                               # рядок 146 — а в attention йде mask
```

`mask` ≠ `μ`. Це два різні числа, і різниця між ними — розділ 5.

### Кроки фьюзії

```python
var_D = (D * (1.0 - D)).clamp(min=_EPS)     # бернуллієва дисперсія, _EPS = 1e-6
var_C = (C * (1.0 - C)).clamp(min=_EPS)
w_D, w_C = 1.0 / var_D, 1.0 / var_C          # чим «впевненіше» джерело, тим більша вага
mu = (w_D * D + w_C * C) / (w_D + w_C)       # зважене середнє
var_total = 1.0 / (w_D + w_C)
confidence = (1.0 - var_total / _MAX_VAR).clamp(min=0.0, max=1.0)   # _MAX_VAR = 0.25
mask = confidence * mu + (1.0 - confidence) * 0.5
```

Ідея: не довіряти геометрії й кольору однаково **скрізь**, а в кожній точці слухати того, хто
впевненіший. Нових learnable-параметрів — нуль.

## 2. Замкнена форма

Якщо помножити чисельник і знаменник на `D(1−D)·C(1−C)`, усе згортається в

```
μ = D·C·(2 − D − C) / [ D(1−D) + C(1−C) ]
```

Звірено з реальним кодом — збігається до 5 знаків на всіх внутрішніх точках
(`test_closed_form_matches_implementation`).

Зверни увагу: **жодної ймовірності тут не лишилось**. Це просто відношення двох многочленів від D і C.
Уся «байєсівськість» була в інтерпретації, а не в арифметиці.

> ⚠️ Замкнена форма і код розходяться **на кутах**: код клемпить дисперсії знизу на `_EPS = 1e-6`,
> тому там, де алгебра дає `0/0`, код видає конкретне число. Це важливо для розділу 4.3.

## 3. 50/50 — окремий випадок нашої формули

Підстав `σ_D = σ_C` — ваги стають рівні, і формула вироджується в `(D+C)/2`, тобто рівно в baseline.
Це не метафора, це перевірено: коли `var_D == var_C` (тобто `D == C` **або** `D == 1−C`), `μ` збігається
з baseline `p` до 1e-5 (`test_identical_when_bernoulli_variances_are_equal` у baseline-тестах).

Тож ми не «додали байєс до наївного фікса». Baseline **уже** був байєсівською фьюзією за припущення
«обидва джерела однаково надійні». Ми лише послабили це припущення, спробувавши оцінити `σ²` з даних.

**Уся суперечка зводиться до одного питання:** чи є `p(1−p)` чесною оцінкою *надійності* джерела?

Ні. `σ² = p(1−p)` — це дисперсія бернуллієвої **випадкової величини**, а не похибка **оцінки** `p`.
У чесній inverse-variance фьюзії `σ²` — це властивість вимірювача, **незалежна** від виміряного
значення. Тут вона є детермінованою функцією самої оцінки. Отже вага кодує «наскільки екстремальне
значення», а не «наскільки надійне джерело». Хто ближче до 0 або 1 — той автоматично «впевненіший».

Усі проблеми нижче — наслідки цього одного факту.

## 4. Властивості — ті самі питання, що й у baseline §4

### 4.1. Помилка НЕ ділиться навпіл — вона може помножитись на 130

Це головна втрата. У baseline зсув `D` на 0.2 **завжди** зсуває результат на 0.1 — рівно половина, за
будь-яких значень (`∂p/∂D = 0.5`, константа). У нас цей коефіцієнт не обмежений нічим:

```
максимальний нахил Δμ/ΔD = 66.87   (заміряно на сітці, при D≈0, C=0.99)
baseline                  =  0.50   (завжди, скрізь)
```

Конкретно — фіксуємо `C = 0.99` і зсуваємо `D` на пів відсотка:

```
D = 0.000  →  μ = 0.000
D = 0.005  →  μ = 0.334
```

Мікроскопічний зсув геометрії — і μ стрибнув на третину діапазону. У baseline той самий зсув дав би
`0.0025`.

**Чому.** Вага `w_D = 1/(D(1−D))`. При `D = 0` вона впирається в клемп і дорівнює **10⁶** — геометрія
забиває колір повністю, `μ ≈ 0`. Але вже при `D = 0.005` вага падає до **201**, ставши порівнянною з
`w_C = 101` — і колір раптом отримує право голосу. Тобто **вибухає не оцінка, а вага**: вона є функцією
оцінки, і біля країв ця функція майже сингулярна.

Ось що ми віддали: **обмежену чутливість**. У baseline жодне джерело не могло перетягнути ковдру.
Тепер — може, і не наполовину, а цілком.

`test_sensitivity_to_one_source_is_unbounded`

### 4.2. Монотонність — зберігається ✅

Більше `D` → більше `μ`. Більше `C` → більше `μ`. Завжди, без винятків (0 порушень на сітці 51×4 по
кожній осі). Тут ми нічого не зламали.

`test_monotone_in_both_priors`

### 4.3. Формула ламається — там, де baseline не ламався

При `D = 1, C = 0` і чисельник, і знаменник — нулі: `0/0`. І це **не діра, яку можна заткнути**, бо
границя залежить від шляху підходу:

| шлях | `μ` при ε → 0 |
|---|---|
| `D = 1−ε`, `C = ε` | **0.5** (ваги рівні, бо `var_D == var_C`) |
| `D = 1−ε`, `C = ε²` | **0** (вага C дотискає D) |

Різні напрямки — різні відповіді, отже значення в цій точці не існує в принципі. Код повертає там
`0.5`, але це артефакт клемпа `_EPS`, а не математика.

`test_limit_at_the_singularity_is_path_dependent`

### 4.4. Де сидить і як гуляє — приблизно як baseline

`μ.std ≈ 0.13-0.29` проти baseline `≈ 0.14` (runtime-таблиця аудиту). По «живості» сигналу ми не
програємо — гіпотеза «мертвих каналів» з ранньої версії аудиту не працює.

## 5. Те, чого в baseline немає

### 5.1. Маска стискається до нейтралі — але щонайбільше наполовину

```python
mask = confidence * mu + (1.0 - confidence) * 0.5
```

Задум: де фьюзія невпевнена — тягнути маску до нейтральних 0.5. Але `confidence` **фізично не може
впасти нижче 0.5**:

- `σ² = p(1−p) ≤ 0.25` для кожного джерела, отже `w = 1/σ² ≥ 4`
- отже `w_sum ≥ 8`, отже `σ²_total = 1/w_sum ≤ **0.125**` — а не 0.25
- отже `confidence = 1 − σ²_total/0.25 ≥ **0.5**`

**`_MAX_VAR = 0.25` — константа нормалізації вдвічі завелика.** Це максимум дисперсії *одного*
Бернуллі, тоді як тут нормується дисперсія *фьюзії двох*. Наслідок: `confidence` використовує лише
верхню половину свого діапазону, а `.clamp(min=0.0)` у коді — недосяжна гілка. Якщо задум був «нехай
confidence пробігає весь [0,1]» — константа мала б бути `0.125`.

Практично: маска систематично підтягнута вгору до 0.5. При `D = C = 0.2` виходить `μ = 0.2`, але
`mask = 0.296`. Це гіпотеза **F3** аудиту, і на реальних даних вона видно: `mu.mean ≈ 0.24` проти
`mask.mean ≈ 0.29`.

`test_confidence_can_never_fall_below_one_half`, `test_agreeing_priors_pull_mask_toward_neutral`

### 5.2. Канал σ²

`σ²_total` подається мережею як окрема вхідна фіча — щоб вона сама вчилась, наскільки довіряти пріору
в кожній точці. Амплітуда ≈ 0.06 ± 0.03 на тлі RGB у [0,1] і μ у [0,1] — гіпотеза **F1** аудиту
припускає, що мережі просто немає за що зачепитись.

## 6. Найгірше: фьюзія знищує сигнал суперечності

Тотожність «паралельних опорів»:

```
σ²_total = (σ²_D · σ²_C) / (σ²_D + σ²_C)  ≤  min(σ²_D, σ²_C)
```

Тобто **будь-яке** екстремальне джерело тягне fused-дисперсію до нуля — **незалежно від того, чи згодне
з ним інше**. Незгода не може підвищити невизначеність, бо математично не має такої можливості.

Крайній випадок:

| | `D` | `C` | `μ` | `σ²_total` | `confidence` | `mask` |
|---|---|---|---|---|---|---|
| суперечність | 1 | 0 | 0.5 | ≈ 5e-7 | ≈ 1 | **0.5** |
| невизначеність | 0.5 | 0.5 | 0.5 | 0.125 | 0.5 | **0.5** |

Точка «геометрія кричить про зміну, колір мовчить» отримує **рівно ту саму маску**, що й точка «ми
нічого не знаємо». При цьому `σ² ≈ 0` каже мережі «вір цьому». Максимальна незгода подається як
нейтральні 0.5 з максимальною впевненістю.

У чесній байєсівській фьюзії розбіжність двох впевнених джерел має **підвищувати** невизначеність або
сигналізувати, що модель неадекватна. Тут інформація просто знищується.

Це гіпотеза **F4** аудиту. Наскільки вона б'є по реальних даних — **невідомо**: `D.sat ≈ 0.02-0.13`,
`C.sat ≈ 0.003`, тож точних `D=1, C=0` мало. Ефект працює й на м'якших розбіжностях, але слабше. Щоб
перевірити, треба додати `D` і `C` у `_dumped_io` (зараз там лише μ/var/mask) і подивитись розподіл
`|D−C|`.

`test_contradicting_priors_yield_confident_neutral_mask`, `test_mask_conflates_contradiction_with_ambiguity`

## 7. І при цьому на типових точках воно = baseline

Стаття калібрує пороги правилом «поріг = 2 × середнє», щоб середня точка датасету відображалась у
`p = 0.5` (див. [baseline §2](prior_mask_math_baseline.md)). А `p = 0.5` — це рівно точка максимуму
дисперсії, **мінімуму** ваги (`w = 4`) і при цьому **стаціонарна** (похідна `1−2p` там нульова).

Тобто правило калібрування статті садить обидва пріори туди, де їхні ваги мінімальні, рівні між собою
і нечутливі до значення. На заміряних середніх HKCD (`D = 0.25`, `C = 0.30`):

```
w_D = 5.33,  w_C = 4.76   →   μ = 0.2736
baseline                       p = 0.275
                        різниця = 0.002
```

**Модифікація нічого не робить у типовому режимі.** Вона діє лише в хвостах розподілу — саме там, де
живуть проблеми з розділів 4.1, 4.3 і 6.

`test_degenerates_to_baseline_at_the_datasets_measured_means` (у baseline-тестах)

## 8. Задум проти формули

Задум маски (сформульовано в обговоренні 2026-07-16):

> Якщо ми впевнені у своїй оцінці — розмиваємо фічі точки тим менше, чим більша оцінка, що там є
> зміни. Якщо не впевнені — розмазуємо з середньою силою, скеровуючи мережу вчити цей випадок,
> але без фанатизму.

Розкладемо на чотири обіцянки і звіримо кожну з тим, що формула реально робить.

### 8.1. «Впевнені, що є зміна → не розмиваємо» — працює, але з підміною

Маска справді висока при екстремальному μ. Але «впевненість» тут — це `p(1−p)`, функція самої
оцінки: формула впевнена тоді, коли значення **екстремальне**, а не коли джерела **згодні**.

```
D = 0.9, C = 0.3   (суттєва незгода джерел!)
w_D = 11.1,  w_C = 4.8   →   μ = 0.72,  conf = 0.75,  mask = 0.66
baseline:                                              p    = 0.60
```

Формула «впевнено» йде за екстремальним джерелом, хоча за задумом незгода мала б тягнути до
обережних 0.5.

### 8.2. «Впевнені, що змін нема → розмиваємо сильно» — прямо порушена

Точка з `D = C = 0.2` — упевнено-незмінна; за задумом її треба сильно придушити, і baseline так і
робить (`mask = 0.2`). У нас:

```
μ = 0.2,   conf = 0.68   →   mask = 0.296
```

Підтяжка до 0.5 працює **знизу теж** — піднімає маску впевнено-незмінних точок, послаблюючи саме те
придушення, яке за задумом мало лишитись. А незмінні точки — більшість хмари.

`test_agreeing_priors_pull_mask_toward_neutral`

### 8.3. «Не впевнені → 0.5, вчися без фанатизму» — механізм майже порожній

Дві причини:

1. У бернуллієвій моделі «велика невизначеність» буває **тільки коли μ і так ≈ 0.5** (висока
   дисперсія ⇔ обидва пріори біля 0.5 ⇔ μ біля 0.5). Підтяжка до 0.5 спрацьовує там, де значення
   вже 0.5 — тягне туди, де воно вже стоїть.
2. Через завелику `_MAX_VAR` `conf ≥ 0.5` завжди (розділ 5.1) — навіть та слабка підтяжка працює
   щонайбільше наполовину.

І головне: «не впевнені» за формулою **ніколи не включає суперечність** — `D=1, C=0` дає
`conf ≈ 1`. Рівно протилежне задуму.

### 8.4. «σ² на вході — нехай мережа сама вчиться довіряти пріору» — канал слабкий і місцями бреше

Амплітуда ≈ 0.06 ± 0.03 (F1, розділ 5.2). Гірше: при суперечності джерел σ² ≈ 0 («вір»), при
чесному «не знаю» σ² = 0.125 («не вір») — сигнал довіри інвертований рівно там, де був би
найціннішим (розділ 6). Зауваж: **конфляція суперечності з невизначеністю в самій масці — не наша
регресія**, baseline дає ті самі 0.5 в обох точках (`0.5·1+0.5·0 = 0.5·0.5+0.5·0.5`); будь-яка
скалярна згортка двох чисел на це приречена. Нове в нас — що ми додали канал, який про цю
конфляцію активно бреше.

### 8.5. Сумарний ефект: два спотворення, що майже гасять одне одного

Дефекти 8.1 і 8.2 діють у протилежні боки: inverse-variance тягне μ до екстремального джерела
(вниз від baseline на переважно-незмінних точках: `μ.mean ≈ 0.24` проти `p.mean ≈ 0.28`), а
підтяжка до 0.5 тягне назад угору (`mask.mean ≈ 0.29`). За runtime-даними аудиту вони майже
**компенсуються**: наша маска статистично ≈ baseline'івська (mean 0.29 проти ~0.28, std порівнянні).
Поточково маски інші — але без систематичного зсуву.

Отже: кожна складова задуму або **підмінена** (впевненість → екстремальність), або **ослаблена**
(`conf ≥ 0.5`), або **порожня** (підтяжка туди, де вже стоїмо) — але на рівні статистики гейта все
це майже скорочується. Єдиний по-справжньому **новий** сигнал проти baseline — канал σ², слабкий і
місцями інвертований.

### 8.6. Що з цього випливає практично

Головні підозрювані у регресії — канал σ² і шум прогону (F2). Найдешевший розрізняльний
експеримент — **A2 з аудиту**: baseline-маска + σ² як єдина нова фіча.

- A2 ≈ baseline → канал невинний, усе впирається в F2 → мультипрогін D.
- A2 < baseline → канал шкодить сам по собі → прибирати, або міняти на чесну міру незгоди
  (наприклад `|D−C|` — вона відрізняє суперечність від невизначеності, чого `σ² = p(1−p)` не вміє
  принципово).

## Підсумок в одному рядку

Ми обміняли **обмежену чутливість і визначеність усюди** на можливість зважувати джерела за надійністю
— але `p(1−p)` вимірює не надійність, а екстремальність. Заплатили твердою валютою, отримали фантик.

І оскільки `σ²` є функцією самого значення, **порогами це не лікується**: підняти поріг → `p→0` →
`σ²→0` → джерело домінує, голосуючи «без змін»; опустити → `p→0.5` → вироджуємось у 50/50. Будь-який
поріг нерозривно задає і «де сидить оцінка», і «наскільки їй вірити». Дефект структурний — лікується
лише заміною самої моделі невизначеності на таку, що не залежить від оцінки.
